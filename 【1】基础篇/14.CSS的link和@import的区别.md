# CSS的link和@import的区别

## 基本概念

link和@import都是用来引入CSS样式表的方法，但它们在实现方式、加载顺序、兼容性等方面有所不同。

```mermaid
graph TD
    A[引入CSS的方法] --> B[link标签]
    A --> C[@import规则]
    
    B --> B1[HTML标签]
    B --> B2[并行加载]
    B --> B3[兼容性好]
    
    C --> C1[CSS规则]
    C --> C2[串行加载]
    C --> C3[兼容性差]
```

## link标签

### 基本语法

```html
<link rel="stylesheet" href="style.css">
```

### 属性说明

| 属性 | 说明 | 示例 |
|------|------|------|
| rel | 关系类型 | rel="stylesheet" |
| href | 样式表路径 | href="style.css" |
| type | 文件类型 | type="text/css" |
| media | 媒体查询 | media="screen" |
| disabled | 是否禁用 | disabled |
| title | 标题 | title="main" |

### 示例

```html
<!-- 基本用法 -->
<link rel="stylesheet" href="style.css">

<!-- 指定媒体类型 -->
<link rel="stylesheet" href="print.css" media="print">

<!-- 指定媒体查询 -->
<link rel="stylesheet" href="mobile.css" media="screen and (max-width: 768px)">

<!-- 禁用样式表 -->
<link rel="stylesheet" href="style.css" disabled>

<!-- 指定类型 -->
<link rel="stylesheet" href="style.css" type="text/css">

<!-- 指定标题 -->
<link rel="stylesheet" href="style.css" title="main">
```

## @import规则

### 基本语法

```css
@import url("style.css");
```

### 语法说明

```css
/* 使用url() */
@import url("style.css");

/* 不使用url() */
@import "style.css";

/* 指定媒体类型 */
@import url("print.css") print;

/* 指定媒体查询 */
@import url("mobile.css") screen and (max-width: 768px);

/* 多个媒体查询 */
@import url("style.css") screen, projection;
```

### 示例

```css
/* 在CSS文件中使用 */
@import url("reset.css");
@import url("base.css");
@import url("layout.css");
@import url("components.css");
@import url("utilities.css");

/* 指定媒体查询 */
@import url("mobile.css") screen and (max-width: 768px);
@import url("print.css") print;
```

## link和@import的区别

### 1. 实现方式

```html
<!-- link：HTML标签 -->
<link rel="stylesheet" href="style.css">
```

```css
/* @import：CSS规则 */
@import url("style.css");
```

### 2. 加载顺序

```html
<!DOCTYPE html>
<html>
<head>
  <!-- link：并行加载 -->
  <link rel="stylesheet" href="style1.css">
  <link rel="stylesheet" href="style2.css">
  <link rel="stylesheet" href="style3.css">
  
  <!-- @import：串行加载 -->
  <style>
    @import url("style4.css");
    @import url("style5.css");
    @import url("style6.css");
  </style>
</head>
<body>
  <!-- 内容 -->
</body>
</html>
```

### 3. 加载时机

```html
<!DOCTYPE html>
<html>
<head>
  <!-- link：页面加载时同时加载 -->
  <link rel="stylesheet" href="style.css">
  
  <!-- @import：等待CSS文件加载完成后再加载 -->
  <style>
    @import url("style.css");
  </style>
</head>
<body>
  <!-- 内容 -->
</body>
</html>
```

### 4. 兼容性

| 浏览器 | link | @import |
|--------|------|--------|
| IE | IE4+ | IE5.5+ |
| Firefox | 全部 | 全部 |
| Chrome | 全部 | 全部 |
| Safari | 全部 | 全部 |
| Opera | 全部 | 全部 |

### 5. DOM控制

```javascript
// link：可以通过JavaScript控制
const link = document.querySelector('link[rel="stylesheet"]');
link.disabled = true;

// @import：无法通过JavaScript控制
// 无法单独控制@import引入的样式表
```

### 6. 性能影响

```html
<!DOCTYPE html>
<html>
<head>
  <!-- link：并行加载，性能更好 -->
  <link rel="stylesheet" href="style1.css">
  <link rel="stylesheet" href="style2.css">
  <link rel="stylesheet" href="style3.css">
  
  <!-- @import：串行加载，性能较差 -->
  <style>
    @import url("style4.css");
    @import url("style5.css");
    @import url("style6.css");
  </style>
</head>
<body>
  <!-- 内容 -->
</body>
</html>
```

## 实际应用

### 1. 使用link引入样式表

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  
  <!-- 重置样式 -->
  <link rel="stylesheet" href="css/reset.css">
  
  <!-- 基础样式 -->
  <link rel="stylesheet" href="css/base.css">
  
  <!-- 布局样式 -->
  <link rel="stylesheet" href="css/layout.css">
  
  <!-- 组件样式 -->
  <link rel="stylesheet" href="css/components.css">
  
  <!-- 工具样式 -->
  <link rel="stylesheet" href="css/utilities.css">
  
  <!-- 响应式样式 -->
  <link rel="stylesheet" href="css/responsive.css" media="screen and (max-width: 768px)">
  
  <!-- 打印样式 -->
  <link rel="stylesheet" href="css/print.css" media="print">
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

### 2. 使用@import引入样式表

```css
/* main.css */
@import url("reset.css");
@import url("base.css");
@import url("layout.css");
@import url("components.css");
@import url("utilities.css");

/* 响应式样式 */
@import url("mobile.css") screen and (max-width: 768px);
@import url("print.css") print;
```

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  
  <!-- 引入主样式表 -->
  <link rel="stylesheet" href="css/main.css">
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

### 3. 混合使用link和@import

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  
  <!-- 使用link引入关键样式 -->
  <link rel="stylesheet" href="css/critical.css">
  
  <!-- 使用@import引入非关键样式 -->
  <style>
    @import url("css/non-critical.css");
  </style>
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

## 最佳实践

### 1. 优先使用link

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  
  <!-- 优先使用link -->
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

### 2. 避免使用@import

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  
  <!-- 避免使用@import -->
  <!-- <style>
    @import url("css/style.css");
  </style> -->
  
  <!-- 使用link代替 -->
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

### 3. 合并样式表

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  
  <!-- 合并后的样式表 -->
  <link rel="stylesheet" href="css/all.css">
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

### 4. 使用预加载

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  
  <!-- 预加载样式表 -->
  <link rel="preload" href="css/style.css" as="style">
  
  <!-- 引入样式表 -->
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

## 总结

| 特性 | link | @import |
|------|------|--------|
| 实现方式 | HTML标签 | CSS规则 |
| 加载顺序 | 并行加载 | 串行加载 |
| 加载时机 | 页面加载时同时加载 | 等待CSS文件加载完成后再加载 |
| 兼容性 | IE4+ | IE5.5+ |
| DOM控制 | 可以控制 | 无法控制 |
| 性能 | 更好 | 较差 |
| 媒体查询 | 支持 | 支持 |

**核心要点：**
1. link是HTML标签，@import是CSS规则
2. link并行加载，@import串行加载
3. link性能更好，@import性能较差
4. link兼容性更好，@import兼容性较差
5. link可以通过JavaScript控制，@import无法控制
6. 优先使用link引入样式表
7. 避免使用@import，特别是不要在CSS文件中使用@import
8. 合并样式表，减少HTTP请求
